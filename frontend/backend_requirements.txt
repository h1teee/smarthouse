# ТРЕБОВАНИЯ И КОНТРАКТЫ ДЛЯ БЭКЕНД-РАЗРАБОТЧИКА (Smart Home MAX)

Этот документ содержит полный перечень эндпоинтов, логики и интеграций, необходимых для того, чтобы связать React-фронтенд (мини-апп) с вашим сервером и ботом в мессенджере MAX.

---

## 1. АРХИТЕКТУРА И ИНТЕГРАЦИЯ С MAX API
Фронтенд — это SPA (Vite/React), работающее внутри WebView мессенджера MAX через `@vkontakte/vk-bridge`.
**Ваша главная задача на бэкенде**:
1. Выдавать фронтенду данные (REST API).
2. Обрабатывать триггеры от УК (одобрение заявки, рассылка) и **делать запросы в API Чат-бота MAX** для отправки PUSH-уведомлений/сообщений жителям.
3. В кнопках сообщений чат-бота генерировать Deep Links на мини-апп. Фронтенд умеет читать параметр `?screen=`.
   *Пример: Боту приказано отправить жителю уведомление. Бот присылает сообщение с кнопкой, ссылка в кнопке: `https://наш-домен.ru/?screen=ukModeration&requestId=123`.*

---

## 2. СПИСОК НЕОБХОДИМЫХ ENDPOINTS (REST API)

Все эндпоинты должны возвращать JSON и обрабатывать заголовки авторизации (например, `Authorization: Bearer <token>`), где токен берется из параметров запуска MAX (VK Bridge).

### БЛОК А: АВТОРИЗАЦИЯ И ПРОФИЛЬ
- `POST /api/auth/login`
  - *Вход:* данные из параметров запуска VK Bridge (sign, user_id).
  - *Выход:* JWT токен, роль пользователя (`resident` | `uk`), привязанный адрес (если есть).
- `POST /api/user/link-address`
  - *Вход:* Адрес, номер квартиры, лицевой счет.
  - *Выход:* 200 OK (привязка лицевого счета).

### БЛОК B: СЦЕНАРИИ ЖИТЕЛЯ
- `GET /api/feed`
  - *Выход:* Массив новостей и отключений по адресу жителя.
- `GET /api/bills`
  - *Выход:* История счетов за ЖКУ (сумма, процент изменения, статус оплаты).
- `GET /api/meters` / `POST /api/meters`
  - *Вход/Выход:* Передача и получение показаний счетчиков (вода, электричество).
- `POST /api/requests/analyze-photo` (ИИ парсинг)
  - *Вход:* `FormData` с изображением объявления (сделано через камеру).
  - *Выход:* Распознанный текст, тип события (вода/свет), даты, время, организация. *(Если ИИ на бэкенде).*
- `POST /api/requests`
  - *Вход:* Подтвержденные данные заявки (тип, сроки, фото).
  - *Выход:* ID созданной заявки (статус: "На модерации").

### БЛОК C: СЦЕНАРИИ УПРАВЛЯЮЩЕЙ КОМПАНИИ (УК)
- `GET /api/uk/requests?status=pending`
  - *Выход:* Список необработанных заявок от жителей (для дашборда).
- `POST /api/uk/requests/:id/approve`
  - *Вход:* Отредактированные модератором поля (заголовок, время, суть).
  - *Логика бэкенда:* Изменить статус заявки -> **Отправить запрос в MAX Bot API** -> Бот рассылает уведомление всем жителям привязанного дома.
- `POST /api/uk/requests/:id/reject`
  - *Вход:* Причина отклонения (`reason`).
  - *Логика бэкенда:* Изменить статус -> **Отправить сообщение в MAX Bot API** автору заявки (с причиной).
- `GET /api/uk/addresses`
  - *Выход:* Список всех обслуживаемых домов/улиц (для выбора в рассылке).
- `POST /api/uk/broadcast`
  - *Вход:* Массив ID адресов (`selectedIds`), категория, текст сообщения.
  - *Логика бэкенда:* **Отправить массовую рассылку через MAX Bot API** по жителям указанных адресов.
- `GET /api/uk/objects`
  - *Выход:* Состояние инфраструктуры по домам (координаты, статус: ok, repair, critical) для карты.
- `GET /api/uk/analytics`
  - *Выход:* Данные для графиков (Сбор платежей, Скорость закрытия заявок, CSI).

## 3. ЧТО НУЖНО СДЕЛАТЬ ПРЯМО СЕЙЧАС (Для интеграции)
1. **Настроить CORS** на сервере, чтобы фронтенд (локальный \`localhost:5173\` и продакшен-домен) мог делать запросы.
2. Предоставить фронтендеру (мне/нам) **Base URL** (например, \`https://api.наш-домен.ru\`).
3. Для хакатона: если нет времени делать сложный ИИ для фото, сделай мок-эндпоинт `/analyze-photo`, который возвращает фейковый успешный JSON через 2 секунды.
4. Создать Чат-бота в МАХ, получить токен и написать скрипт отправки сообщений от имени бота (для `/approve` и `/broadcast`).

Во фронтенде везде заложены стейты \`isLoading\`, функции \`try/catch\` и компоненты ожидания. Как только эндпоинты будут готовы, мы просто вставим \`fetch()\` в подготовленные пустые функции (например, \`handleSubmit\` в рассылке).
